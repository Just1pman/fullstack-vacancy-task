# Список пользователей

Можно искать пользователей по имени, добавлять и удалять записи. Сервер хранит данные в памяти и восстанавливает начальный список при перезапуске.

## Локальный запуск

Понадобятся Node.js 24 и npm. Выполните команду из каталога решения.

```sh
npm install --no-package-lock && npm run build && npm start
```

Откройте [127.0.0.1:3000](http://127.0.0.1:3000/).

## Технологии

Сервер обслуживает REST API через `node:http`, клиент использует HTML, CSS и `fetch`. Обе части написаны на TypeScript и используют общие типы API. Пакеты нужны только для сборки.
