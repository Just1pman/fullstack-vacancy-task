# Пользователи

Для запуска нужны Node.js 22 или новее и npm.

Из корня репозитория перейдите в каталог решения:

```bash
cd submissions/trybachok
```

Установите зависимости для сборки:

```bash
npm ci
```

Создайте локальный файл настроек:

```bash
cp .env.example .env
```

В `.env` задаются адрес прослушивания (`HOST`), порт (`PORT`), каталог статических файлов (`PUBLIC_DIR`) и путь к начальному списку пользователей (`USERS_FILE`).
Если `.env` уже создан, добавьте `USERS_FILE=data/users.json`.
Относительные пути отсчитываются от каталога решения. Переменные окружения имеют приоритет над значениями в файле.

При запуске сервер открывает JSON-файл с правами на чтение и запись и загружает список в память. Файл служит источником начальных данных. Изменения списка хранятся в памяти и сбрасываются при перезапуске.

Соберите и запустите сервер:

```bash
npm start
```

С настройками из примера откройте приложение на [http://127.0.0.1:3000](http://127.0.0.1:3000).

Сервер написан на TypeScript и использует встроенные модули Node.js. Браузер получает HTML и CSS.

[Контракт REST API](openapi.yaml) описывает операции с пользователями, серверную валидацию и ответы на ошибки.

## Тесты

```bash
npm test
```

Команда собирает TypeScript и запускает тесты через встроенный `node:test`.
