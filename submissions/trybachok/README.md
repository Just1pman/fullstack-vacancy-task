# Пользователи

Для запуска нужны Node.js 22 или новее и npm.

Из корня репозитория перейдите в каталог решения:

```bash
cd submissions/trybachok
```

Установите зависимости для сборки:

```bash
npm ci
```

Соберите и запустите сервер:

```bash
npm start
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000).

Сервер написан на TypeScript и использует встроенные модули Node.js. Браузер получает HTML и CSS.

[Контракт REST API](openapi.yaml) описывает операции с пользователями, серверную валидацию и ответы на ошибки.

## Тесты

```bash
npm test
```

Команда собирает TypeScript и запускает тесты через встроенный `node:test`.
